# Oracle Active Data Guard (ADG) Configuration Guide

## 1. Environment

| Parameter | Value |
|----------|------|
| ORACLE_SID | BYTEWORK |
| ORACLE_HOME | /data/u01/app/oracle/product/19.0.0/dbhome_19 |
| DB_UNIQUE_NAME (Primary) | ByteWorks |
| DB_UNIQUE_NAME (Standby) | ByteWorks_standby |
| Archive Location | /data/archivelog/ByteWorks |

---

## 2. Network Configuration

### Primary & Standby (tnsnames.ora)

```ini
BYTEWORK_PRIMARY =
  (DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=PRIMARY_IP)(PORT=1521))
  (CONNECT_DATA=(SERVICE_NAME=BYTEWORK_PRIMARY)))

BYTEWORK_STANDBY =
  (DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=STANDBY_IP)(PORT=1521))
  (CONNECT_DATA=(SERVICE_NAME=BYTEWORK_STANDBY)))
```

## 4. Enable Archivelog

```sql
ARCHIVE LOG LIST; SHUTDOWN IMMEDIATE; STARTUP MOUNT; ALTER DATABASE ARCHIVELOG; ALTER DATABASE OPEN;
```

---

## 5. DB Unique Name

```sql
ALTER SYSTEM SET db_unique_name='ByteWorks' SCOPE=BOTH;
ALTER SYSTEM SET db_unique_name='ByteWorks_standby' SCOPE=BOTH;
```

---

## 6. Data Guard Configuration

### Primary

```sql
ALTER SYSTEM SET LOG_ARCHIVE_CONFIG='DG_CONFIG=(ByteWorks,ByteWorks_standby)' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_DEST_1='LOCATION=/data/archivelog/ByteWorks VALID_FOR=(ALL_LOGFILES,ALL_ROLES) DB_UNIQUE_NAME=ByteWorks' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_DEST_2='SERVICE=BYTEWORK_STANDBY ASYNC VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=ByteWorks_standby' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_FORMAT='%t_%s_%r.arc' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_MAX_PROCESSES=4 SCOPE=BOTH;
ALTER SYSTEM SET DB_FILE_NAME_CONVERT='/data/oradata/ByteWorks_standby','/data/oradata/ByteWorks' SCOPE=BOTH;
ALTER SYSTEM SET LOG_FILE_NAME_CONVERT='/data/oradata/ByteWorks_standby','/data/oradata/ByteWorks' SCOPE=BOTH;
ALTER SYSTEM SET STANDBY_FILE_MANAGEMENT=AUTO SCOPE=BOTH;
ALTER SYSTEM SET FAL_SERVER=BYTEWORK_STANDBY SCOPE=BOTH;
ALTER SYSTEM SET FAL_CLIENT=BYTEWORK_PRIMARY SCOPE=BOTH;
ALTER SYSTEM SET REMOTE_LOGIN_PASSWORDFILE=EXCLUSIVE SCOPE=BOTH;
```

---

### Standby

```sql
ALTER SYSTEM SET LOG_ARCHIVE_CONFIG='DG_CONFIG=(ByteWorks,ByteWorks_standby)' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_DEST_1='LOCATION=/data/archivelog/ByteWorks VALID_FOR=(ALL_LOGFILES,ALL_ROLES) DB_UNIQUE_NAME=ByteWorks_standby' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_DEST_2='SERVICE=BYTEWORK_PRIMARY ASYNC VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=ByteWorks' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_FORMAT='%t_%s_%r.arc' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_MAX_PROCESSES=4 SCOPE=BOTH;
ALTER SYSTEM SET DB_FILE_NAME_CONVERT='/data/oradata/ByteWorks','/data/oradata/ByteWorks_standby' SCOPE=BOTH;
ALTER SYSTEM SET LOG_FILE_NAME_CONVERT='/data/oradata/ByteWorks','/data/oradata/ByteWorks_standby' SCOPE=BOTH;
ALTER SYSTEM SET STANDBY_FILE_MANAGEMENT=AUTO SCOPE=BOTH;
ALTER SYSTEM SET FAL_SERVER=BYTEWORK_PRIMARY SCOPE=BOTH;
ALTER SYSTEM SET FAL_CLIENT=BYTEWORK_STANDBY SCOPE=BOTH;
ALTER SYSTEM SET REMOTE_LOGIN_PASSWORDFILE=EXCLUSIVE SCOPE=BOTH;
```

## 8. Create Standby (RMAN)

```rman
recover standby database from service BYTEWORK_PRIMARY;
```

---

## 9. Open Standby

```sql
ALTER DATABASE OPEN READ ONLY;
```

---

## 10. Enable MRP

```sql
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE DISCONNECT USING CURRENT LOGFILE;
```

---

## 11. Validation

```sql
SELECT NAME, OPEN_MODE, DATABASE_ROLE FROM V$DATABASE;
SELECT PROCESS, STATUS, THREAD#, SEQUENCE# FROM V$MANAGED_STANDBY;
```

---

## 12. Check Replication Lag

```sql
ALTER SESSION SET nls_date_format='DD-MM-YYYY HH24:MI:SS';
SELECT A.THREAD#, B.LAST_SEQ, A.APPLIED_SEQ, A.LAST_APP_TIMESTAMP, B.LAST_SEQ-A.APPLIED_SEQ ARC_DIFF FROM (SELECT THREAD#, MAX(SEQUENCE#) APPLIED_SEQ, MAX(NEXT_TIME) LAST_APP_TIMESTAMP FROM GV$ARCHIVED_LOG WHERE APPLIED='YES' GROUP BY THREAD#) A,(SELECT THREAD#, MAX(SEQUENCE#) LAST_SEQ FROM GV$ARCHIVED_LOG GROUP BY THREAD#) B WHERE A.THREAD#=B.THREAD#;
```
